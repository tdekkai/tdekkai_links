# TDekkai Links — Caio Marcus Souza

Microsite pessoal estático, desenvolvido com HTML, CSS e JavaScript para hospedagem gratuita no GitHub Pages. Não depende de build ou Node.js.

## Como publicar
1. Crie um repositório **público** no GitHub (por exemplo, `TDekkai-Links`).
2. Envie `index.html`, `styles.css`, `script.js` e a pasta `assets/` **para a raiz** do repositório.
3. Em **Settings > Pages**, selecione **Deploy from a branch**, `main`, `/(root)` e salve.
4. O endereço padrão será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Cuidados
- Não publicar senhas, tokens, chaves privadas, endereços ou dados pessoais sensíveis: GitHub Pages de repositório público publica o código.
- Todo o site é estático; não armazena dados de visitantes nem configura analytics.
- Fontes Google Fonts requerem acesso à internet; caso contrário, o site usa fontes alternativas.
