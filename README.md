# Caio Marcus Souza — Links (Versão 6)

Microsite mobile-first, estático, para GitHub Pages.

## Publicação
1. No repositório `tdekkai/tdekkai_links`, envie os arquivos `index.html`, `styles.css` e a pasta `assets/` **diretamente para a raiz** (sem uma pasta intermediária).
2. Em **Settings → Pages**, selecione **Deploy from a branch**, **main** e **/(root)**.
3. Abra https://tdekkai.github.io/tdekkai_links/ após o deploy.

## Conteúdo
- Sobre mim: Instagram, LinkedIn, podcast Spatial Hackers #17.
- Minha comunidade: Instagram, LinkedIn, YouTube e webinar GeoSPACE.
- Minha consultoria: site, Instagram, LinkedIn e YouTube Dekkai Insights.

Não utiliza bibliotecas externas. Miniaturas vetoriais de podcast e webinar são ilustrações originais simplificadas, não capas oficiais. Para mudar links e textos, edite `index.html`. Para alterar cores e espaçamentos, edite `styles.css`.
